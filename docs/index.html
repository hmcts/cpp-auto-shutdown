How to read this board

State is observed, not assumed

State now is what live verification last found, read from the state file — it is never worked out from the clock. Where it disagrees with the schedule the row says so.

Partly up means the components disagree: the application may be running while the database is stopped. The line underneath names which.

A failed check never blanks the record

When a check fails, the last known result is kept and the platform team is alerted. So a failed check shows as a reading that stops getting newer, not as an empty one.

Last checked 14 hours ago means the value shown is real but possibly out of date. Never checked means this stack has no verified result at all.

A request only counts once it is applied

Automation reads applied configuration only. A request that has not been approved and applied has no effect — the environment will still shut down at its usual time.

Not approved needs an approver. Approved, not applied means approval happened but the change never reached the schedule, which is one for the platform team.

Hours

Baseline is 06:00 to 19:00, Europe/London. Shutdown can be delayed to 21:00, 23:00 or run for 24 hours, and weekends run only where a stack opts in.

Stacks stay down on bank holidays unless an exception covers the day. Full detail is in DESIGN.md.
